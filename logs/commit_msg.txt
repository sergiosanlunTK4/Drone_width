fix: 'source bashrc' cortaba los scripts + lanzador foam_run.py sin dependencia de source

EJECUCION REAL EN WSL (primera vez que se prueba el codigo en el entorno destino) y
aparecieron DOS BUGS.

BUG 1 — `source .../etc/bashrc` DENTRO de un script CORTA la ejecucion en seco.
  Sintoma: `bash scripts/verify_cfd_prereqs.sh` imprimia
      -- 2. Entorno OpenFOAM
      [AVISO] blockMesh NO esta en PATH; intentando cargar el entorno...
  y MORIA ahi, en silencio, sin seguir con el resto de comprobaciones.
  Causa: el bashrc de OpenFOAM esta pensado para shell INTERACTIVA (imprime banner y
  termina el proceso). Los tres .sh lo hacian y se cortaban.
  -> Corregido: los .sh YA NO hacen source. Si el entorno no esta cargado, ABORTAN con
     instrucciones claras en vez de morir en silencio.
  -> Nuevo scripts/foam_run.py: construye el entorno SIN hacer source dentro del script.
     Estrategia: (1) si blockMesh ya esta en PATH no toca nada; (2) captura el entorno
     parseando la salida del envoltorio `openfoam2412`; (3) si falla, lo captura en un
     SUBSHELL (`bash -c 'source ...; env'`), donde el corte no nos afecta porque solo nos
     importa su salida. Luego ejecuta el comando con ese entorno.

BUG 2 — `wsl -d Ubuntu --` no funciona desde DENTRO de WSL (es comando de PowerShell).
  Dentro de Ubuntu se usa `bash -lc`.
